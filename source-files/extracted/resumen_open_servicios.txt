Resumen práctico — Ecosistema CONDOR / Open
Open ofrece principalmente el ecosistema CONDOR, compuesto por soluciones de RRHH, ERP, autogestión, proveedores, analytics y cloud. La web lo presenta como software de gestión para empresas medianas y grandes, con foco en RRHH, ERP e IA.

Cómo entenderlo rápido
Condor Work es el mundo de RRHH.Ahí están empleados, sueldos, legajos, ausencias y recibos. Para Infra es sensible porque maneja información personal y salarial.
Condor Enterprise es el mundo administrativo/ERP.Ahí están compras, finanzas, proveedores, stock, tesorería y contabilidad. Para Infra suele ser crítico porque si se cae puede frenar la operación del cliente.
Condor Link es la cara más “web/app” para los empleados.Es importante porque normalmente requiere publicación segura, certificados SSL, reverse proxy y control de exposición.
Condor ProvIA complementa al ERP con proveedores e IA.Puede manejar facturas, órdenes de compra y aprobaciones. Desde Infra hay que mirar integraciones, almacenamiento de documentos y seguridad.
Condor Analytics es la capa de reportes y tableros.No siempre es una app transaccional, pero puede pegarle fuerte a la base si consulta directo a producción.
Condor Cloud no es una app funcional, sino el modelo donde alojamos todo.Ahí entran servidores, VMs, base Oracle, WebLogic, firewalls, VPNs, backups, monitoreo, certificados y disponibilidad.

Cliente └── Producto CONDOR      ├── Work HR        → RRHH / sueldos / legajos      ├── Enterprise ERP → administración / compras / finanzas      ├── Link           → app web/mobile para empleados      ├── ProvIA         → proveedores + IA      ├── Analytics      → BI / reportes      └── Cloud          → infraestructura donde corre todo
